# Edge Gestures for Chrome

复刻 Microsoft Edge 右键滑动手势的 Chrome 扩展（MV3、零构建、零网络请求）。

按住**右键拖动**触发手势，**纯右键点击正常弹出菜单**（依赖 Windows Chrome
contextmenu 在 mouseup 之后触发的事件时序）。

## 安装（开发者模式加载）

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本目录（`edge-gestures-chrome/`）
4. 建议在「详情」里把该扩展设为「在无痕模式下启用」按需开启

## 手势表（与 Edge 114+ 的 16 种一致，无对角线）

| 笔画 | 动作 | | 笔画 | 动作 |
|---|---|---|---|---|
| ← | 后退 | | ↑← / ↑→ | 切换左/右标签页 |
| → | 前进 | | ↓← | 停止加载 |
| ↑ | 向上滚动一屏 | | ←↓ | 关闭所有标签页 |
| ↓ | 向下滚动一屏 | | ↑↓ | 滚动到页面底部 |
| ↓→ / ←→ | 关闭标签页 | | ↓↑ | 滚动到页面顶部 |
| ←↑ / →← | 恢复关闭的标签页 | | →↑ | 打开新标签页 |
| →↓ | 刷新 | | | |

## 视觉参数（来自 2026-10-11 录屏逐帧量测 + PNG 地面真值）

| 参数 | 值 |
|---|---|
| 轨迹颜色 | `#0078D4`（Edge 品牌蓝） |
| 轨迹宽度 | 6.5 设备px ≈ 4.33 CSS px @150% 缩放（恒定、圆头、无锥形） |
| 消失动画 | 松手后 1 帧整体消失，无淡出 |
| 气泡底色 | `rgba(0,0,0,0.70)` |
| 气泡位置 | 视口正中心（与手势位置无关） |
| 气泡尺寸/圆角 | ≈300×148 CSS px / ≈26px |
| 气泡内容 | 白色方向图标（实时绘制笔画路径，每段带箭头）+ 白色动作名（≈21px） |
| 实时联动 | 气泡文字 = 当前笔画与手势表的实时匹配结果；松手时提示的动作 = 实际执行的动作 |

以上参数可在扩展「选项」页调整（触发距离、转向阈值、颜色、宽度等）。

## 结构

```
manifest.json            MV3 清单
shared/gestures.js       手势表 + 默认配置（内容页/设置页共用常量）
content/engine.js        识别引擎：方向分段（正交投影 + 转向阈值）+ 序列匹配
content/trail.js         轨迹渲染（canvas 覆盖层，rAF 重绘，DPR 适配）
content/bubble.js        提示气泡（SVG 方向图标 + 动作文字，视口居中）
content/scroll.js        平滑滚动（225ms easeOutCubic，用户输入可打断）
content/actions.js       动作分发（页面内直接执行 / 转发 background）
content/main.js          事件状态机（mousedown/move/up/contextmenu）
background/…             chrome.tabs / chrome.sessions 动作
options/…                设置页
icons/…                  扩展图标（工具栏点击打开设置页）
dev/preview.html         渲染预览页（开发用）
```

### 行为细节

- 拖动过但**不匹配任何手势**：不执行动作，同时吞掉右键菜单（与「拖动即手势」语义一致）
- 手势进行中按 `Esc` / 拖出窗口 / 窗口失焦：取消手势，不执行动作
- 在 iframe 内松开右键（顶层收不到 mouseup）：残留手势会被自动作废，不会误触发
- **↑↓ / ↓↑（滚到底/滚到顶）的第二笔长度按半阈值计**（垂直轴折返更容易触发），
  ←→ / →←（关标签/恢复标签）保持完整阈值

## 已知限制（扩展平台天花板，无法绕过）

- `chrome://` 页面、Chrome 商店、PDF 查看器、新标签页无法注入内容脚本 → 手势无效
- 全屏视频之上画不出轨迹（fullscreen 顶层元素遮盖）
- iframe 内起始的拖动：轨迹被 iframe 边界裁剪、iframe 外收不到事件（M4 计划做跨帧汇总）
- 与「右键拖动画布」类网站（Figma、地图）存在冲突，Edge 原生同样存在
